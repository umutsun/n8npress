**Guiding principles:**
- **Hard deps stay minimal**: WooCommerce + one translation plugin (WPML or Polylang). Everything else (Rank Math, Elementor, cache, SMTP) is soft.
- **Never write to third-party plugin databases**: read their meta, call their hooks, but never push into FluentCRM/Mailchimp/Klaviyo contact lists.
- **REST-first settings**: every module exposes `GET/POST /<module>/settings` (partial-update) for uniform remote management.
